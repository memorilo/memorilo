# 滴答清单（DIDA 365）功能特点调研

调研日期：2026-08-16

## 范围与证据边界

本文调查的是中国区官网 `dida365.com` 及其官方帮助中心当前公开的产品能力，不把 TickTick 国际版的价格、集成或数据政策直接套用于滴答清单。功能事实优先引用官网功能页、会员页、下载页和官方帮助文章；“产品分析”是基于这些事实作出的归纳，不代表官方产品定义。

帮助中心在调研当日已出现 2026 年新增的 AI、MCP 与 CLI 文档，因此本文按 2026-08-16 可访问页面描述当前能力。客户端版本、灰度、公测、设备和会员条件仍可能使实际可用性不同。

## 结论摘要

滴答清单已经不是单一的勾选式 Todo 工具，而是一套围绕同一批任务数据组织的个人生产力系统：前端强调低摩擦收集，中段用清单、标签、过滤器、层级和多种视图组织，执行阶段接入日历时间块、提醒、专注和习惯，末端再用统计、摘要和 AI 做复盘。共享清单、Notion 双向同步、日历订阅、MCP 与 CLI 又把任务延伸到了团队和自动化工作流中。[官方功能页](https://dida365.com/features?language=zh_CN)；[AI 使用案例](https://help.dida365.com/articles/7475108284236562432)（均访问于 2026-08-16）

其最鲜明的交互特点是“先快速捕获，再渐进整理”：手机端以随处可见且可移动的 `+` 为入口，桌面端有常驻添加栏和全局快捷键，文本或语音中的时间可自动识别；进入详情后才逐步补充日期、时间段、提醒、重复、清单、标签、优先级、描述、检查事项和附件。[添加任务](https://help.dida365.com/articles/6950658877373284352)；[任务详情与编辑](https://help.dida365.com/articles/6950661731483910144)（均访问于 2026-08-16）

## 一、官方确认的功能事实

### 1. 核心任务管理

- **快速收集入口很多**：移动端 `+`、小组件、桌面任务添加栏、Windows/macOS 全局快捷键 `Ctrl/Cmd + Alt + A`、语音、微信、邮件、Siri、剪贴板和手表均可创建任务。桌面添加栏支持 `Shift + Enter` 转入描述编辑；移动端添加栏顺序和 `+` 的左右位置可以自定义。[添加任务](https://help.dida365.com/articles/6950658877373284352)（访问于 2026-08-16）
- **自然语言时间识别**：输入“1 月 10 号下午两点补油漆”等文本时，产品会识别日期和时间并设置任务时间；用户可以删除识别结果或关闭该能力。官网还明确列出语音转文字和智能识别时间。[添加任务](https://help.dida365.com/articles/6950658877373284352)；[官方功能页](https://dida365.com/features?language=zh_CN)（均访问于 2026-08-16）
- **任务属性较完整**：任务支持单日或跨日时间段、四级优先级（高/中/低/无）、清单、标签、富文本/Markdown 描述、检查事项、图片/录音/文件/视频附件、置顶、放弃、评论、内部链接、副本、模板、动态记录，以及任务与笔记互转。[任务详情与编辑](https://help.dida365.com/articles/6950661731483910144)（访问于 2026-08-16）
- **任务可递归拆解**：子任务在功能上仍是完整任务，可单独设时间、专注、描述、标签、优先级和指派；当前最多支持五级嵌套。已有任务可以通过拖拽变成子任务，层级可以展开/收起；排序只在同层任务间比较。检查事项与子任务可同时存在，但官方说明主任务进度只受检查事项完成情况影响。[多级任务](https://help.dida365.com/articles/6950660746367729664)（访问于 2026-08-16）
- **多维组织**：普通清单和文件夹负责稳定分类，标签提供跨清单维度，过滤器可按清单、标签、日期、优先级、关键词等组合；高级筛选支持“且/或”逻辑和预览。[官方功能页](https://dida365.com/features?language=zh_CN)；[过滤器](https://help.dida365.com/articles/6950655961044353024)（均访问于 2026-08-16）
- **同一任务可有多种投影视图**：官网列出列表、看板、时间线；此外还有日历和四象限。时间线把任务时长映射为横向长度，支持拖动调整开始/结束时间和拖拽边缘改变时长，并可按日、周、月改变观察尺度；智能清单不支持时间线视图。[官方功能页](https://dida365.com/features?language=zh_CN)；[时间线视图](https://help.dida365.com/articles/6950656549178048512)（均访问于 2026-08-16）

### 2. 提醒、日历与时间规划

- **提醒类型丰富**：普通提醒之外，官网列出多提醒、结束时提醒、持续响铃、微信提醒、重复提醒、iOS 位置提醒和艾宾浩斯提醒。重复规则包括周/月/年、法定工作日或节假日、农历月/年。[官方功能页](https://dida365.com/features?language=zh_CN)（访问于 2026-08-16）
- **日历视图不仅用于查看，也用于排程**：官方列出年、月、周、日程、多日、多周视图。周视图区分全天区和竖向时间轴，可直接在时间轴创建时间段任务、拖动任务改期、拖动边缘改时长，也能把无日期任务从“安排任务”栏拖入日历；移动端还有日/三日视图，桌面端有多日/多周视图。[官方功能页](https://dida365.com/features?language=zh_CN)；[周视图](https://help.dida365.com/articles/6950641140068515840)（均访问于 2026-08-16）
- **外部日历双向延伸但方式不同**：滴答清单可订阅本地、Google、iCloud、Outlook、Exchange、企业微信、钉钉、飞书、QQ 邮箱和 URL 日历；也能生成 URL，让 Google、Outlook 等第三方日历订阅滴答清单内容。[日历订阅](https://help.dida365.com/articles/6949998599191134208)；[在第三方日历中订阅滴答清单](https://help.dida365.com/articles/6950000444106080256)（均访问于 2026-08-16）

### 3. 习惯、专注与复盘

- **习惯是独立模块而不是重复任务的别名**：可从 60 多个预设习惯中选择或自定义名称、图标、鼓励语、频率和量化目标；支持周频率、每日数量目标、日志、月度打卡表、年度热力图、周/月统计和小组件。[开始坚持一个习惯](https://help.dida365.com/articles/6950379455722291200)；[习惯数据统计](https://help.dida365.com/articles/7005344825801179136)（均访问于 2026-08-16）
- **专注同时支持番茄倒计时和正计时**：默认番茄节奏为 25 分钟专注加 5 分钟休息，也可持续正计时；专注记录可关联到任务、记录专注笔记、事后补记或修正时长，并可开启多端同步。统计包含年/月/周趋势、每天的专注时间线、最佳专注时段、年度热力图，以及按清单、标签、任务查看投入分布。[如何开始专注](https://help.dida365.com/articles/6950408124297641984)；[专注数据统计](https://help.dida365.com/articles/6950408300395495424)（均访问于 2026-08-16）
- **复盘形成任务到笔记的闭环**：任务和笔记是并列类型，二者可互转；笔记支持模板和看板。任务摘要可以按时间、清单、状态、标签、优先级和指派人筛选，把完成情况、进度、多级任务和专注数据生成可编辑文本并插入笔记或导出。[笔记与摘要](https://help.dida365.com/articles/6950671600370843648)（访问于 2026-08-16）

### 4. 共享与协作

- **协作边界是普通清单**：自己创建的普通清单可以共享；“今天”“明天”等智能清单和收集箱不能共享。邀请支持邮箱、共享链接和 App 端微信二维码。[如何共享清单](https://help.dida365.com/articles/6950649257581871104)（访问于 2026-08-16）
- **共享后具备基本项目协作能力**：成员可指派任务、批量指派、在评论中 `@` 他人、接收通知中心消息，并分别控制任务完成/添加/删除等变更通知。成员权限可设为可编辑、可评论或只读；任务动态记录责任人和历史修改，清单动态目前只在电脑端查看。[团队如何协作](https://help.dida365.com/articles/6950652002518958080)（访问于 2026-08-16）
- **容量依赖清单所有者会员状态**：官方帮助说明，只要共享清单所有者是高级会员，该清单最多可共享给 29 个成员；其他成员不必都是高级会员，但不能使用自身账户未包含的高级功能。[团队如何协作](https://help.dida365.com/articles/6950652002518958080)（访问于 2026-08-16）

### 5. 跨平台、集成与自动化

- **客户端覆盖面广**：官方下载页提供 Web、iOS/iPadOS、Android、HarmonyOS、Windows、macOS、Linux 和插件入口；帮助中心还明确描述手机、电脑、平板、网页和手表场景，账号数据可跨端同步。[官方下载页](https://dida365.com/download?language=zh_CN)；[全平台支持](https://help.dida365.com/articles/6950366447398813696)（均访问于 2026-08-16）
- **微信集成针对中国用户的收集习惯**：公众号对话支持文字、图片、语音、网页并能创建任务、识别提醒；“滴答小助手”用于把聊天中的文字、图片、网页和聊天记录转发进 `#微信采集`。官方 FAQ 明确小助手属于高级会员功能。[玩转微信](https://help.dida365.com/articles/6949994885164302336)（访问于 2026-08-16）
- **Notion 是有限字段的双向同步，而非简单导入**：可以用官方模板新建数据库，也可授权已有数据库；标题、日期、描述和状态等映射后可双向同步。首次同步聚焦最近编辑的 200 条内容/未完成任务；其他 8 类 Notion 属性最多展示 4 个且只读。删除或把任务移出关联清单会同步影响 Notion 内容。[关联 Notion](https://help.dida365.com/articles/7263009022960205824)（访问于 2026-08-16）
- **还有 Siri、邮件、日历 URL 和 URL Scheme 等入口**：Siri 可创建任务或打开指定智能清单，邮件可转成任务；官网资源区提供 URL Scheme 文档。[Siri](https://help.dida365.com/articles/6950042073403752448)；[添加任务](https://help.dida365.com/articles/6950658877373284352)；[官方首页](https://dida365.com/)（均访问于 2026-08-16）

### 6. 智能与 AI 能力

需要区分两类“智能”：传统的自然语言日期识别、智能清单和规则过滤器是确定性任务管理能力；2026 年帮助中心新增的 AI 语音、录音总结、AI 摘要、MCP 和 CLI 才构成生成式 AI/agent 能力。

- **AI 语音添加**：从自然表达中提取标题、日期、时间、清单、标签和优先级；一段话含多件事时可拆成多条任务，长语音则可提炼标题并把全文转写放入描述。处理失败会回退到普通语音文本；官方说明每月有额度，语音仅用于当次处理、不保存且不用于模型训练。[AI 语音添加任务](https://help.dida365.com/articles/7444666114547646464)（访问于 2026-08-16）
- **AI 录音**：录音附件可生成带时间戳的转写或结构化总结，点击文本可跳到对应播放位置；支持 30 多种语言，后台处理，结果可复制、加入描述或分享。该能力同样有月度额度。[AI 录音总结](https://help.dida365.com/articles/7444668968427585536)（访问于 2026-08-16）
- **AI 摘要仍是公测且仅 Web**：系统根据已完成任务提取重点并优化表达，用于项目收尾、日报和周报。[笔记与摘要](https://help.dida365.com/articles/6950671600370843648)（访问于 2026-08-16）
- **MCP 把任务系统开放给外部 AI 客户端**：官方远程 MCP 支持 Streamable HTTP，以 OAuth 或 Bearer Token 授权。工具不只查询/创建/完成任务，还覆盖清单、分组、文件夹、批量修改、评论、指派、标签、习惯、专注记录等，包含删除类写操作；官方给出 Claude、ChatGPT、Gemini、Claude Code、Cursor、VS Code、Codex 等连接方式。[滴答清单 MCP](https://help.dida365.com/articles/7438132116019216384)（访问于 2026-08-16）
- **DIDA CLI 提供脚本化入口**：官方 CLI 文档列出登录、清单查询、任务创建/完成/删除等命令，并说明目前主要覆盖任务、清单、习惯、专注和纪念日的基础操作，尚未支持全部高级功能。[DIDA CLI](https://help.dida365.com/articles/7464976698707017728)（访问于 2026-08-16）
- **官方给出的 AI 使用方向是系统维护而非单次问答**：示例包括整理收集箱、制定今日计划、清理积压、检查任务系统健康度、每日/每周复盘和长期时间投入分析；这些案例依赖 MCP 或 CLI 读写数据。[AI 使用案例](https://help.dida365.com/articles/7475108284236562432)（访问于 2026-08-16）

## 二、产品交互与定位分析（非官方事实）

### 1. “捕获—澄清—安排—执行—复盘”是一条完整链路

滴答清单把 GTD 式工作流做进了产品结构，而不是只提供一个任务表：收集箱和多入口降低捕获成本；清单、标签、优先级、层级和过滤器负责澄清；日历与时间线负责安排；提醒和专注推动执行；统计、摘要、笔记和 AI 负责复盘。每一环仍围绕同一个任务对象，因此用户不必在多个应用间反复搬运数据。

### 2. 交互策略是“默认简单，能力渐进暴露”

新建任务时只输入一句话即可完成；复杂能力主要藏在添加栏快捷控件、详情页、右键菜单、`...` 菜单和可选功能模块中。移动端允许调整 `+` 的位置和添加栏顺序，桌面端强调键盘、命令和拖拽。这使新用户可以把它当普通 Todo 使用，重度用户再逐渐建立过滤、模板、日历、专注和自动化流程。

### 3. 视图不是独立内容容器，而是任务数据的不同投影

列表适合逐项处理，看板适合按分组看状态，时间线适合看跨度和依赖，日历适合 time blocking，四象限适合优先级判断，过滤器适合动态聚合。拖拽和缩放让“改计划”发生在视图内，而不是必须打开表单。这种多投影设计是其从 Todo 向轻量项目管理扩展的关键。

### 4. 中国区的差异化在本地生态，长期扩展点在开放接口

微信收集/提醒、农历与法定节假日重复、HarmonyOS、企业微信/钉钉/飞书日历等能力明显针对中国用户；Notion 双向同步、日历 URL、MCP 和 CLI 则面向跨工具和 agent 工作流。两类集成共同强化了“任务入口不必发生在滴答清单界面里”的产品观念。

### 5. AI 的价值主要来自结构化任务数据，而非独立聊天 UI

当前公开证据最强的 AI 能力是输入结构化、录音处理、摘要，以及通过 MCP/CLI 让外部 agent 操作已有数据。未找到官方证据证明滴答清单内已提供一个覆盖所有数据的通用聊天助手。更准确的定位是：AI 被嵌入捕获和复盘节点，同时开放结构化工具给外部 AI，而不是用聊天界面替代原有任务管理交互。

### 6. 采用或借鉴时应关注的边界

- 功能广度很高，但部分能力受平台、版本、会员和灰度限制；实现类似产品时需要清楚表达可用条件。
- 同一官方站点的附件日限额出现 `99` 与 `199` 两种说法，说明帮助文档可能存在更新不同步，容量类数据不应作为长期稳定契约。
- MCP 提供删除任务、评论和文件夹等写操作，自动化能力强，但产品设计必须配套授权范围、危险操作确认、审计与撤销/垃圾箱策略。
- Notion 同步存在首次 200 条、字段映射、只读属性、权限重授权和删除传播等规则，说明“支持双向同步”背后需要显式展示同步边界和冲突后果。
